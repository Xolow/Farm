# Текстовая ферма

Консольный симулятор по варианту 17 лабораторной работы.

## Запуск

Требуются [uv](https://docs.astral.sh/uv/) и Python 3.8 или новее:

```powershell
uv sync
uv run main.py
```

Команды: `plant`, `water`, `harvest`, `status`, `sell`, `help`, `exit`.

Начальный баланс — 100. Посадка пшеницы стоит 10, а сбор готового урожая приносит 15 денег. Дождь может ускорить рост, вредители — повредить или уничтожить культуру, а удачный урожай добавляет бонус к следующему сбору.

Игровые функции находятся в `main.py`, данные культуры и цены — в `farm_data.py`. Случайные события воспроизводимы благодаря фиксированному `random.seed(42)`.
