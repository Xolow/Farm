# Текстовая ферма

Консольный симулятор фермы по варианту 17 лабораторной работы 4. На ферме можно выращивать пшеницу, морковь и картофель. У каждой культуры своя стадия роста, а общие баланс и бонус относятся ко всей ферме.

## Запуск

Требуются [uv](https://docs.astral.sh/uv/) и Python 3.8 или новее:

```bash
uv sync
uv run main.py
```

Команды `plant`, `water` и `harvest` сажают, поливают и собирают культуру. Можно указать её название после команды, например `plant морковь`, `water морковь`, `harvest морковь`. Без названия используется пшеница. Повторная посадка уже растущей культуры не расходует деньги.

Команда `describe морковь` выводит описание культуры, `status` — стадии всех культур и готовые к сбору, `sell` — баланс, `help` — подсказку, `exit` — завершает игру. Если у `describe` не указать культуру, будет показана пшеница.

Начальный баланс — 100 монет. Посадка стоит 10 монет, сбор на стадии 3 приносит 15 монет и накопленный бонус. После успешного действия случайное событие может ускорить рост культуры, повредить её или добавить бонус к следующему сбору. Событие роста или повреждения применяется к культуре, указанной в команде. Случайные события воспроизводимы благодаря `random.seed(42)`.

Список культур и описания находятся в `farm_data.py`, игровые функции — в `main.py`. Стадии хранятся в словаре, готовые культуры — во множестве. `ready_crops` и `crops_upper` формируют списки с помощью генераторов списков.

## Тесты

```bash
uv sync --group dev
uv run pytest
```

Тесты проверяют функции для готовых культур, описаний и преобразования названий, а также игровые сценарии.
