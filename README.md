# Текстовая ферма

Консольный симулятор фермы по варианту 17 лабораторной работы 5. На ферме можно выращивать пшеницу, морковь и картофель. У каждой культуры своя стадия роста, а общие баланс и бонус относятся ко всей ферме.

## Запуск

Требуется Python 3.8 или новее. Программа не требует сторонних библиотек:

```bash
python3 main.py
```

Команды `plant`, `water` и `harvest` сажают, поливают и собирают культуру. Можно указать её название после команды, например `plant морковь`, `water морковь`, `harvest морковь`. Без названия используется пшеница. Повторная посадка уже растущей культуры не расходует деньги.

Команда `describe морковь` выводит описание культуры, `status` — стадии грядок, созревшие и растущие культуры, животных и инвентарь, `sell` — баланс, `help` — подсказку, `exit` — завершает игру. Если у `describe` не указать культуру, будет показана пшеница.

Команда `save` сохраняет деньги, грядки, животных, инвентарь и бонус урожая в файл `farm_save.json` в текущей папке. Команда `load` восстанавливает сохранение; при ошибке чтения текущее состояние фермы сохраняется. Файл сохранения исключён из Git. В начале игры на ферме есть корова и курица; команда `status` показывает, каких животных нужно покормить.

Начальный баланс — 100 монет. Посадка стоит 10 монет, сбор на стадии 3 приносит 15 монет и накопленный бонус. После успешного действия случайное событие может ускорить рост культуры, повредить её или добавить бонус к следующему сбору. Событие роста или повреждения применяется к культуре, указанной в команде. Случайные события воспроизводимы благодаря `random.seed(42)`.

Список культур и описания находятся в `farm_data.py`, игровые функции — в `main.py`, работа с JSON — в `storage.py`. Стадии хранятся в словаре, готовые культуры — во множестве. Списки созревших и растущих культур, голодных животных и отчётов о грядках формируются генераторами списков.

## Тесты

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest
```

В Windows вместо команды `source` используйте `.venv\Scripts\activate`.

Тесты проверяют сохранение и загрузку, обработку ошибок, генераторы списков и игровые сценарии. Для запуска отдельного файла, например, используйте `python -m pytest tests/test_storage.py -v`.
