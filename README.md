# Текстовая ферма

Консольный симулятор по варианту 17 лабораторной работы.

## Запуск

Требуются [uv](https://docs.astral.sh/uv/) и Python 3.8 или новее:

```powershell
uv sync
uv run main.py
```

Команды: `plant`, `water`, `harvest`, `status`, `sell`, `exit`.

Посадка стоит 10 денег, начальный баланс — 100. Две поливки после посадки доводят культуру до стадии 3; сбор готового урожая добавляет 15 денег.

Зависимости и их версии управляются через `pyproject.toml` и `uv.lock`. Внешние пакеты проекту не требуются.
